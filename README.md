# db_spp_desi
Aplikasi pembayaran spp menggunakan website untuk mempermudahkan pengguna, menggunakan PHP dan MYSQL, untuk memudahkan pengelolaan dan penvcatatan transaksi SPP sekolah.Memiliki dua Hak akses dalam aplikasi yaitu sebagai Admin dan Petugas. Sistem keamanan password pengguna menggunakan fungsi MD5 agar ke amanan data akun tetap terjaga. Pengelolaan data master, yaitu admin dapat mengelola seluruh data utama pendukung sistem, yang meliputi:
Data siswa(mengelola data identitas siswa lengkap (NISN, Nama, Kelas,dsb).
Data Kelas(Mengatur data kelas dan jurusan).
Data petugas(Mengatur Akun pengguna untuk petugas maupun admin).
dan Data SPP(menentukan nominal serta tarif SPP per tahun ajaran).
lalu ada Transaksi dan catatan pembayaran SPP, Mencari cepat siswa, menginput pembayaran, Hisyori dan Rekap.
 Fitur Cek status Tanpa Login juga terse3dia(Akses siswa/Orang tua)
 Database aplikasi ini terdiri dari 5 tabel relasi yaitu:
 Siswa(menyimpan data identitas siswa)
 pembayaran(Menyimpan rekap data transaksi pmbayaran SPP)
 petugas(menyimpan data petugas/admin serta akun login)
 kelas ( menyimpan daftar kelas siswa)
 dan spp(menyimpan data acuan nominal tarif SPP)
